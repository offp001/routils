# Dependencies

RoUtils uses Python and the packages listed in `requirements.txt`.

## Requirements

- **Python 3.12 or newer** for the Windows build instructions.
- Git, if you plan to clone the repository.
- A compatible Python environment with the dependencies listed in `requirements.txt`.

When installing Python on Windows, enable **Add Python to PATH** so that Python and pip can be accessed from the terminal.

## Installing Dependencies

Install the required packages using:

```bash
python -m pip install -r requirements.txt
```

Make sure you're using the intended Python environment before installing packages.
