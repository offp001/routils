## Features

### Cache Editor

- **3D Preview** — View cached Roblox meshes and models directly within RoUtils.
- **Image Preview** — Preview cached PNG and other image assets.
- **Audio Preview** — Preview cached OGG and MP3 files.
- **Dump** — Extract Roblox cache files into organized folders.
- **Export** — Export individual cache entries in supported formats:
  - `Full Blob`
  - `RBXM`
  - `Image`
  - `Video`
  - `OBJ`
- **Copy / Save Hash** — Copy or save cache hashes.
- **Delete Cache Type** — Remove cached data from a selected category.

#### How Cache Editor Works

RoUtils reads cache data generated by the Roblox client and organizes available files into categories.

When the **Cache** tab is opened, RoUtils scans the Roblox cache database and identifies available cached assets. Depending on the asset type, additional information or previews may be available.

Supported categories include:

- Mesh
- Model / RBXM
- Animation
- Image
- Audio
- Video
- Font
- Text
- Unknown

Select a cache entry to inspect it. Supported assets can be previewed directly in RoUtils, including 3D models, images, and audio files.

**Dump Caches** extracts cached files and stores them in the RoUtils Dump folder, organized by category.

The **Export** options provide different ways to export selected cache entries:

- **Full Blob** — Export the complete cache blob.
- **RBXM** — Export compatible Roblox model data.
- **Image** — Export image assets.
- **Copy / Save Hash** — Copy or save a cache hash for later use.

**Delete Cache Type** removes cached data belonging to a selected category. For example, selecting `Image` removes cached image data without requiring each file to be deleted individually.

RoUtils is designed to keep cache operations from unnecessarily blocking the main interface.

### FFlag Manager

- **FFlag Injector** — Apply FFlags to Roblox.
- **Saved JSONs** — Save and load FFlag JSON configurations.
- **Hotkeys** — Apply or change supported values using keyboard shortcuts.
- **Presets** — Load FFlag presets from the RoUtils GitHub repository.
- **JSON Editor** — Edit FFlag JSON configurations directly.
- **Default FFlags / Offsets / Values** — View lists of FFlags, offsets, and values.

#### How FFlag Manager Works

FFlags (Fast Flags) are configuration values used by Roblox to control client behavior and features.

RoUtils provides an interface for creating, editing, and applying FFlag configurations without manually editing configuration files.

**Basic workflow:**

`FFlags → JSON Editor → Paste JSON → Add → Apply`

Open the **JSON Editor** and paste a configuration in JSON format. After adding it, apply the configuration through RoUtils.

Example:

```json
{
  "FFlagExample": "True"
}
```

RoUtils provides a `jsons` folder for storing saved `.json` configurations. Saved files appear in FFlag Manager, allowing configurations to be selected and applied later.

**Saved JSONs** allow multiple configurations to be maintained and reused.

**Presets** provide ready-made FFlag configurations from the RoUtils GitHub repository. These can be added to the current configuration.

**Hotkeys** allow supported FFlag values to be changed or applied using configured keyboard shortcuts.

**Default FFlag Values** opens the default Roblox FFlag values list.

**Latest FFlag List** provides a list of currently tracked FFlags for inspecting available names and values.

### Subplace Joiner

- **Subplace Joiner** — Join Roblox subplaces using a Universe ID or Place ID.
- **Copy Deep Link** — Copy the generated Roblox deep link.

#### How Subplace Joiner Works

A Roblox experience can contain multiple places, commonly referred to as subplaces.

Subplace Joiner allows a specific Roblox place to be targeted by entering its **Place ID** or the relevant **Universe ID** information. This provides an alternative to navigating to the place manually through the main experience.

#### Place ID vs. Universe ID

A **Place ID** identifies a specific place within a Roblox experience. An experience may contain a main lobby, a map, a loading place, a trading place, or another game mode, each with its own Place ID.

A **Universe ID** identifies the overall Roblox experience, which can contain multiple places.

When targeting a specific subplace, the Place ID is the relevant identifier. After generating a join link, use **Copy Deep Link** to copy it to the clipboard.

> For experiences containing multiple places, use the Place ID to target the intended subplace.

### Server Viewer

- **Server Information** — Inspect available server information without joining through a deep link.
- **Place ID**
- **Job ID**
- **Players**
- **Max Capacity**
- **Ping**
- **Server FPS**
- **Location**

#### How Server Viewer Works

Server Viewer allows available public Roblox server information to be inspected before joining.

The game's **Place ID** and the server's **Job ID** identify the relevant place and server instance.

#### What Is a Job ID?

A **Job ID** uniquely identifies a running Roblox server instance.

A Place ID identifies the game or place, while a Job ID identifies a particular server running that place.

Example:

```text
Place ID:
123456789

Job ID:
xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

Multiple servers can host the same Place ID simultaneously, with each server having its own Job ID.

```text
Place ID = Which game/place?
Job ID   = Which server?
```

Depending on data availability, Server Viewer can display:

- **Place ID** — The Roblox place being hosted.
- **Job ID** — The unique server instance identifier.
- **Players** — The current number of players.
- **Max Capacity** — The maximum player capacity.
- **Ping** — Reported server or network latency.
- **Server FPS** — Available server-side performance information.
- **Location** — Server location or region, when available.

### History

- **Game History** — Save game history and reopen previously visited games.
- **Server History** — Keep a record of recently visited servers and return to them.

### Client

- **Client Information** — Display CPU and RAM usage alongside the current Game ID and Job ID.
- **FPS Changer** — Change Roblox's FPS limit.
- **FPS Hotkeys** — Change the FPS limit using keyboard shortcuts.
